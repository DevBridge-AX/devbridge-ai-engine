# 코드 리뷰 규칙

## 리뷰어 지정
- PR 하나당 리뷰어는 최소 2명이며, 그중 1명은 해당 모듈의 코드 오너여야 합니다.
- 리뷰 요청 후 영업일 기준 24시간 안에 첫 응답을 남기는 것이 원칙입니다.

## PR 크기
- 변경 줄 수는 400줄 이하를 권장하고, 800줄을 넘으면 PR을 분리해야 합니다.
- 자동 생성 코드와 락 파일은 줄 수 계산에서 제외합니다.

## 승인 조건
- CI의 린트와 단위 테스트가 모두 통과해야 머지할 수 있습니다.
- 리뷰어 2명이 Approve 하면 작성자가 직접 Squash Merge 합니다.
- 코멘트 접두어로 `[필수]`, `[제안]`, `[질문]`을 구분하며 `[필수]`만 머지 차단 사유입니다.

## 금지 사항
- 주석 처리된 코드를 남긴 채 머지하지 않습니다.
- 담당자 A가 관리하는 공통 모듈은 사전 협의 없이 수정하지 않습니다.
