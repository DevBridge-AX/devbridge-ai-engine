# 로그 보존 정책

## 보존 기간
- 애플리케이션 로그(INFO 이상)는 30일간 보관한 뒤 자동 삭제합니다.
- DEBUG 로그는 운영 환경에서 수집하지 않으며, 스테이징에서는 7일만 보관합니다.
- 접속 로그(액세스 로그)는 90일간 보관합니다.

## 저장 위치
- 최근 7일치는 검색 속도를 위해 로그 검색 클러스터에 두고, 이후에는 압축하여 객체 스토리지 `logs-archive` 버킷으로 옮깁니다.

## 삭제와 예외
- 삭제 작업은 매일 05:00에 정리 스크립트가 수행합니다.
- 장애 조사가 진행 중인 로그는 담당자 A의 승인을 받아 최대 14일까지 보존 기간을 연장할 수 있습니다.
- 로그에는 비밀번호와 토큰을 남기지 않으며, 발견되면 즉시 마스킹 처리합니다.
