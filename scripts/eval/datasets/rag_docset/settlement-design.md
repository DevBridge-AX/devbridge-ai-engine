# 결제 정산 과제 설계 (정산 개선 과제)

이 문서는 정산 개선 과제 팀 내부용 설계안입니다.

## 목표
- 가맹점별 일 정산을 D+1 오전 9시까지 완료합니다.

## 처리 흐름
1. 전일 00:00~24:00 승인 건을 `PAYMENT_APPROVED` 테이블에서 집계합니다.
2. 가맹점 수수료율을 적용하며 기본 수수료율은 2.5%, 우수 가맹점은 1.8%입니다.
3. 취소 건은 정산 대상에서 차감하고, 차감 후 금액이 음수이면 다음 날 정산으로 이월합니다.
4. 결과를 `SETTLEMENT_DAILY` 테이블에 저장한 뒤 은행 이체 파일을 생성합니다.

## 미결정 사항
- 부분 취소 건의 수수료 환급 방식은 담당자 B와 협의가 필요합니다.
