# 개발 환경 배포 절차

개발(dev) 환경은 main 브랜치에 병합되면 자동으로 배포됩니다.

## 배포 단계
1. 병합 직후 CI가 컨테이너 이미지를 빌드하며 평균 6분이 걸립니다.
2. 빌드가 끝나면 dev 클러스터에 롤링 방식으로 배포하고, 파드는 한 번에 2개씩 교체합니다.
3. 배포 후 스모크 테스트 12개가 통과하지 않으면 직전 버전으로 자동 복구합니다.

## 규칙
- 별도 승인 절차와 배포 시간대 제한이 없습니다.
- 배포 결과는 #dev-deploy 채널로 알림이 갑니다.
- 보관하는 이미지는 최근 10개입니다.
