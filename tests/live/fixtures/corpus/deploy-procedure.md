# 배포 절차

## 배포 전략

운영 환경 배포는 **blue-green 전략**을 사용합니다. 신규 버전을 별도 슬롯에 띄운 뒤
헬스체크 통과 시 트래픽을 전환하며, 문제가 발견되면 즉시 이전 슬롯으로 되돌립니다.

## 배포 명령어

배포는 아래 스크립트로 실행합니다.

```
./deploy.sh --env production --strategy blue-green --tag <release-tag>
```

`--tag` 값은 반드시 태그된 릴리스 커밋 해시를 사용해야 하며, `latest`나 브랜치명을
직접 지정하는 것은 금지합니다.

## 배포 가능 시간

배포는 매주 화요일, 목요일 오후 3시(15:00)에만 진행합니다. 그 외 시간에 배포하려면
인프라팀장의 사전 승인이 필요합니다. 금요일 배포는 원칙적으로 금지합니다.

## 배포 승인자

배포 승인자는 인프라팀장이며, 배포 전 체크리스트(빌드 성공 여부, 마이그레이션 스크립트
검토, 롤백 계획)를 확인한 뒤 승인합니다.

## 배포 후 확인 절차

1. `/health` 엔드포인트 200 응답 확인
2. 에러율 대시보드에서 5분간 5xx 비율이 0.5% 미만인지 확인
3. 신규 슬롯 트래픽 전환 후 10분간 모니터링 유지
