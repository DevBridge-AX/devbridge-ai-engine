# 배포 전 점검 체크리스트

이 문서는 DevBridge AX 프로젝트의 운영 배포 전 점검 항목을 정리한 가상 문서입니다.

## 점검 항목

1. `main` 브랜치의 모든 테스트가 통과했는지 확인한다.
2. `.env` 설정 값 중 `GMS_API_KEY`, `DATABASE_URL`이 운영 값으로 채워졌는지 확인한다.
3. 최근 배포에서 발생했던 `Timeout` 에러가 재발하지 않는지 스테이징에서 재현 테스트한다.
4. 결제 API 연동 부분은 별도 QA 승인 없이는 배포하지 않는다 (security 관련 이슈 우려).
5. 배포 완료 후 `deploy.sh --env production` 로그를 5분간 모니터링한다.

## 알려진 이슈

- 지난주 배포에서 세션 만료 처리 중 `FIXME`로 남겨둔 임시 코드가 있다. 다음 배포 전
  정식 로직으로 교체가 필요하다.
- 결제 실패 재시도 로직에 대한 리스크가 아직 완전히 해소되지 않았다.
